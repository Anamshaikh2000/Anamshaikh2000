# 🚀 Featured Projects

## 🧠 SQLPilot — AI-Powered SQL Assistant

**Python · Streamlit · Groq API · SQLite · Pandas · PyPDF · Generative AI**

An AI-powered SQL assistant that converts natural-language questions into SQL queries, executes them against a database, and analyzes SQL queries from uploaded PDF documents.

### ✨ Key Features

- Built a **Natural Language → SQL** generation workflow
- Generates SQL queries using **Groq LLMs**
- Executes generated queries against a temporary **SQLite database**
- Displays query results in a structured table
- Supports multiple tables and SQL **JOIN** operations
- Built a **PDF SQL Analyzer** for reviewing SQL questions and queries
- Identifies incorrect SQL queries and explains the issues
- Generates corrected SQL queries
- Uses environment variables to securely manage API credentials
- Built an interactive **Streamlit interface**

🔗 [**View SQLPilot Repository**](https://github.com/Anamshaikh2000/SQLPilot)

## 🔎 SemanticLens — AI-Powered Document Intelligence

**Python · LangChain · FAISS · Groq API · Streamlit · RAG**

A Retrieval-Augmented Generation application designed to make large technical documents easier to search and understand.

### ✨ Key Features

- Built an end-to-end **RAG pipeline**
- Processed large telecom Knowledge Transfer documents
- Generated embeddings for document content
- Used **FAISS** for semantic similarity search
- Retrieved relevant document context
- Generated context-aware answers using **Groq API**
- Built an interactive **Streamlit interface**
- Reduced manual KT document lookup time by approximately **70%**
